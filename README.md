# Hi, I'm Soroush 👋

I'm Soroush Yousefpour (gabrimatic), a senior software engineer in Berlin. I build mobile apps and AI tools, with a focus on local inference, voice, and coding agents.

I started with native Android and iOS development and have worked with Flutter in production since 2019.

## 🎙️ Local AI

- [Local Whisper](https://github.com/gabrimatic/local-whisper): on-device dictation and transcription for macOS, iOS, and Android, with desktop shortcuts and mobile keyboards.
- [kokoro-mlx](https://github.com/gabrimatic/kokoro-mlx) and [qwen3-asr-mlx](https://github.com/gabrimatic/qwen3-asr-mlx): MLX inference libraries for Kokoro text-to-speech and Qwen3-ASR speech recognition on Apple Silicon.
- [OCR Capture](https://github.com/gabrimatic/ocr-capture): copy text from a screen region or image using Apple's on-device Vision framework.
- [Threadstone](https://github.com/gabrimatic/threadstone): offline terminal chat with MLX models on Apple Silicon, with streaming replies and session recovery.
- [Ollama Flutter GUI](https://github.com/gabrimatic/ollama_flutter_gui) and [personal_ollama_cli](https://github.com/gabrimatic/personal_ollama_cli): a Flutter Web interface and a terminal client for local Ollama models.

## 🛠️ Tools for agents

- [tmux-mcp](https://github.com/gabrimatic/tmux-mcp): persistent terminals for AI agents. You can attach to the same session, see what's happening, and take over.
- [MCP Web Search Tool](https://github.com/gabrimatic/mcp-web-search-tool): web search, page reading, and source citations for assistants.
- [mcp-prose-memory](https://github.com/gabrimatic/mcp-prose-memory): structured memory that agents can keep across sessions.
- [Copilot Goal System](https://github.com/gabrimatic/copilot-goal-system): persistent goals, progress tracking, and completion checks for longer Copilot tasks.
- [Agent Flight Recorder](https://github.com/gabrimatic/agent-flight-recorder): a local record of code changes, commands, and test runs to help review an agent's work.
- [Realtime Operator](https://github.com/gabrimatic/realtime-operator): voice control for local tools on your computer, using the OpenAI Realtime API.
